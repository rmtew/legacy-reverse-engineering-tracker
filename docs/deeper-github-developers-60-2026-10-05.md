# Deeper GitHub and related-developer discovery — 2026-10-05

Added **60 source-reviewed projects**, taking the catalogue from **1,320 to 1,380**. This is exactly the approved candidate set. No audit-only lead, previously reviewed collision, or unreviewed search result was promoted.

## Scope and verification

All sixty projects received eight-area audits covering identity, classification, source CPU, target CPU, build status, runtime profiles, AI attribution and relationships. Primary metadata, README, implementation source, build/configuration, commit evidence and rights/provenance materials were inspected.

No candidate was compiled, installed, run, played or hardware-tested during this review. Positive build/runtime/playability flags are explicitly bounded upstream reports; unknown is retained where evidence is missing. All byte-exact flags remain unknown. Generic emulators, source-derived ports, tools, firmware, homebrew, patches and partial engine/game reconstructions remain distinctly classified.

## Platform and CPU label decisions

Existing canonical SC-3000, SG-1000, Master System, VIC-20, NES and Oric-1 spellings are reused. CPC464/CPC6128 labels are used only with model evidence; family-only sources remain Amstrad CPC. No existing catalogue record or global historical alias was rewritten.

- **Olivetti Prodest PC1:** Existing DOS label; exact PC1/Yamaha V6355D 16-colour mode and original-game requirement remain in notes and a documented runtime profile.
- **Commodore 64 DTV:** Existing Commodore 64 family; exact 65DTV02 profile details remain in notes/audits, without asserting a new minimum or new machine alias.
- **SwinSID Nano:** New distinct firmware-board platform, supported by Makefile and firmware source. Typed CPU is AVR; exact ATmega88/ATmega88A and 32 MHz remain profile details, not C64 6510 or guessed minimum.
- **NEC PC-8001:** New distinct source-machine label: dwimsy explicitly documents current WAV/T88 streaming conversion for this family. Tape format evidence does not imply a source CPU claim.
- **NEC PC-8801:** New distinct source-machine label: native T88/protocol implementation and the documented Dig Dug capture example directly substantiate coverage.
- **Playdate:** New distinct Downland target: actual C platform implementation, SDK 2.7.5 instructions and device/simulator build path substantiate the machine.
- **ESP32 Cheap Yellow Display:** Exact ESP32-2432S028 CYD board retained in notes. Experimental Arduino/TFT_eSPI port is below half speed upstream and has empty sound functions; no new typed platform or guessed CPU.

README explicitly says the project source codes are currently PRIVATE. Tools may be interesting, but claims and binary archives do not meet the source-backed threshold. No project is added by this decision. No build or runtime verification was performed.

No build or runtime verification was performed.

Keep out of this higher-confidence batch. No project is added by this decision. No build or runtime verification was performed.

## Important retained caveats

- The partial RoadBlasters STE enhancement needs original game code and debugger-loaded overlays; there is no standalone disk release. Defender of the Crown enhancement source references absent external includes.
- Icicle Race does not publish the PC Engine/SNES ports implied by its repository name; Bungeling Bay retains binary inclusions. These are not full semantic reconstructions or independently byte-matched builds.
- C64RED is original Pokémon-inspired homebrew. Bubble Bobble PC1 is DOS graphics patching with C64-derived artwork, not a C64 port.
- SIDM2conv’s CI test step has continue-on-error and an upstream-reported failing test subset. A green workflow must not be treated as a clean test suite.
- MGI’s engine families have widely different partial capability; it explicitly claims no completable title. SwosDS has source lineage and conflicting asset-redistribution statements.
- Lazy Jones’s game-specific static-recompilation/hardware-runtime hybrid stays a deferred audit lead. It is not silently relabelled as clean native gameplay reconstruction.
- Fairlight’s custom rights-holder source-available terms are not an unrestricted open-source license. Other projects retain missing/mixed notices and original ROM/game/artwork restrictions.
- Twenty-three records have explicit AI attribution. Scope and primary evidence are preserved, including Qasteroids’ removed historical Lovable/Claude wording. Agent configuration alone is not treated as quantitative authorship evidence.
