## Research event notes

Root personally searched 20 platform/type queries and inspected 17 selected new or alternate roots: 11 additions, three lineage duplicates and three deferrals. Screening also rejected already tracked roots and irrelevant keyword matches. Amiga, CPC, Spectrum, BBC/Electron, C64, DOS, PC-98, Saturn and Apple II/IIgs sources were considered; this is not a claim of exhaustive platform coverage. No discovery worker used. Read-only upstream source inspection, no builds or proprietary image downloads. Each cached proof is bound to a separately fetched commit, matching pinned file listing and Git blob hash. Ingestion lessons: GitHub fork flags alone do not distinguish a meaningful continuation from a duplicate; follow explicit upstream/successor links. Bare README goals and stale copied documentation are insufficient. Distinguish original source preservation, native developer utilities, decompiler output and playable reconstruction. Hardware-independent input formats do not imply host CPU minima. Restricted assembler support, colour truncation, missing historical programs and custom checksum semantics are retained as limitations. No baked-emulation classification is inferred from I/O shims, tape animation or debugger integration. Source review does not prove binary matching or robustness. Six previously decided URLs are represented by updated source reviews rather than duplicate decision rows. The earlier DOSBox integration deferral is addressed by inspecting the manifest and actual debugger protocol implementation; its promotion supersedes that dated uncertainty. Existing duplicate/exclusion decisions remain preserved.
