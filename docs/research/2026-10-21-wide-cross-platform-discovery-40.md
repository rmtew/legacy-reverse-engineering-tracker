## Research event notes

Root personally ran 52 broad searches, returning 585 hits and 582 distinct repository URLs; 40 selected roots including the canonical CPC upstream were reviewed. No discovery worker was used. Search coverage spans classic computers, consoles, games, disassemblies, decompilations, source archives, language tools, emulators, hardware tests, media tools and filesystem tooling. Coverage is broad, not an assertion that every project was exhausted. Source tree, README, implementation and selected fork comparisons were inspected; no upstream code was executed. Ingestion findings: search token collisions (BBC Micro versus micro:bit); documentation-only forks and renamed-owner links; explicit broken historical sources remain valuable without runnable claims; model inference/MCP/agent configuration must not imply development-AI authorship; format/container limits and source/target CPU direction must survive ingestion. Large GitHub Contents API responses can return empty content without isError: blob fallback recovered seven large catalogue files; such empty results must not mean missing evidence. Used a connector-pinned current catalogue snapshot after shell Git access failed; no stale checkout used for duplicate decisions. Local dry-run uses current catalogue/audit/source/decision snapshots with an older unchanged activity file because the 14 MB current activity blob exceeds the connector fetch limit; repository CI/application must validate against the live activity file before publication is considered complete.
