# Seventeen Amiga game projects

Published 17 approved, source-reviewed games and collections, taking the catalogue from 1,715 to 1,732. This games-only pass covers original author source archives, substantive native homebrew, and reconstructions of Amiga game subjects.

## Scope and verification

Fresh baseline: main f8c70d18333dad71c511eda424fadd2627c5f6fc. All baseline tracked Git blobs, catalogue/source/decision indexes and a 2,031-root prior-review union were checked before promotion. Ermentrud/Inga has two source roots but one record; AmigaBridge is one collection with three inspected game anchors. Related mirrors/ports are not counted as additional independent games.

Exactly 136 project-specific audit areas are supported by primary sources. All independent compilation, runtime, playability and byte-identity flags remain unknown. Existing binaries, release packages, compiler options, upstream claims and source-complete-looking trees do not replace local tests. No candidate game was built, installed or executed.

Native 68k, OCS/AGA/RTG and PPC variants stay separate from modern host reconstructions. Minimum CPU/RAM/chipset fields are only populated from explicit output-specific evidence; a compiler flag does not automatically establish a runnable minimum. Original-source recovery is distinguished from binary-derived reconstruction.

AI labels require affirmative author/commit attribution. Computer-opponent logic, provider domains, filenames and configuration instructions alone are not authorship evidence. The existing collector/application/schema/workflow code, PR4 attribution labels, known SDL attribution false positive and DMPP’s corrected 2017-04-07 activity date remain unchanged.
