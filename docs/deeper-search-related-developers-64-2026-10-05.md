## Non-promoted decisions

- [kevedwards/timgeofffollinmusicdevdiskarchive](https://github.com/kevedwards/timgeofffollinmusicdevdiskarchive): **duplicate**. README explicitly identifies this as a second recovery pass on the same Tim/Geoff Follin Einstein music-development disks previously recovered in already tracked breakintoprogram/archive-follin. Adds repaired/damaged data, raw IMG/DSK images, disk photos and K-prefixed newly archived disks; record as an alternate/additional preservation source rather than a second musical-driver project.
- [guybrush-atari/sonic-ste](https://github.com/guybrush-atari/sonic-ste): **deferred**. Tree has only .gitignore, README.md and Sonic-STe-0.8-alpha.zip; no primary implementation/build source inspected. The ZIP was not downloaded or executed, so do not assert its contents are binary-only.
- [atari-legend/legacy](https://github.com/atari-legend/legacy): **excluded**. Legacy AtariLegend public website and CPANEL PHP/MySQL control-panel implementation, not Atari hardware/software reconstruction, original native retro code, a game port or emulation tool.
- [CPC Mastering tools](https://github.com/reidrac/cpc-mastering): **duplicate**. Build/packaging collection includes already tracked iDSK plus 2CDT and gfx2crtc. Own dump-pal.py (MIT header) and BASIC loader are useful, but conservatively avoid separately counting this mostly vendored mastering bundle as new independent tooling.
- [SG1000 multicart (xrip)](https://github.com/xrip/sg1000-multicart): **duplicate**. README explicitly says heavily based on already tracked aotta/SD-1000 and uses its PCB. Firmware/menu changes are real, but retain as derivative lineage rather than inflate independent project count.
- [SG1000 target for Crab/tms9918lib](https://github.com/cdoty/sg1000): **duplicate**. Platform wrapper/startup for tms9918lib and Crab. Count with accepted cdoty/tms9918lib rather than treating its submodule distribution as another independent library/game.
- [Conquest](https://github.com/creationix/conquest): **deferred**. README calls it a Lords of Conquest remake and says it remains unfinished. The inspected complete client.js renders countries/resources and changes random ownership/icons when clicked; index.html launches it directly. No substantive playable rules implementation is established by the inspected map/click scaffold.
- [Augmentinel](https://github.com/simonowen/augmentinel): **excluded**. README explicitly states the original gameplay runs by emulating the Spectrum version of The Sentinel. Spectrum.cpp accesses original game's memory addresses; repository contains Z80 core, Spectrum ROM and game snapshot, while C++/D3D11 supplies modern rendering/VR. Visual Studio 2019+ build and GPLv3 source license are documented. Game-specific original-CPU emulation is audit-only under current scope; do not promote as a native reimplementation.
- [kevedwards/exilearchives](https://github.com/kevedwards/exilearchives): **deferred**. Historical prerelease disk and binary archive, with photos and exported executable files; no substantive newly reconstructed implementation or recovered editable game source identified in the inspected tree. Useful preservation source, not another Exile implementation. Retain as a preservation source; editable recovered implementation evidence needs further inspection before any project promotion.
- [f-fix/pc88_tape_tools](https://github.com/f-fix/pc88_tape_tools): **duplicate**. Substantive PC-8001/PC-8801 tape implementation, but already tracked dwimsy explicitly extracts/refactors this core and keeps it as its verification baseline. Retain as upstream provenance rather than add another same-core record in this batch. Direct README AI attribution belongs to this upstream and should not be automatically copied to all dwimsy code.
- [vaspervnp/projectkaptara](https://github.com/vaspervnp/projectkaptara): **deferred**. Only CPC setup/title/display and an empty gameplay self-jump are implemented. Retain the inspected evidence as a lead, not a native-game candidate. This applies the same threshold as Conquest.
