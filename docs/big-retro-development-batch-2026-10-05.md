# Big retro-development discovery batch — 2026-10-05

47 primary-source candidate reviews: 44 promotions, one duplicate, two exclusions, zero deferrals. Catalogue: 1,160 → 1,204 projects.

## Evidence and verification

Candidates were screened against the current project/source/decision indexes before primary review. Existing exact hits were not re-opened as fresh candidates. All added records have explicit eight-area research audits. No independent game compile or gameplay session was conducted. Documented builds, releases, gameplay and bounded comparison results are attributed to upstream; current volamos CI execution logs were inspected. Unsupported facts remain unknown.

All links identify coherent repository roots. Native game implementations are distinguished from game-specific CPU wrappers; generic emulator/development tools remain eligible. Separate reference CPU interpreters and sound-chip models do not turn a verified native game path into game-specific emulation.
