# Platform-matrix and remake-list discovery — 2026-10-05

Added **65 source-reviewed projects**, taking the catalogue from **1,204 to 1,269**. The same approved set contains 64 distinct GitHub roots and one coherent author-site remake family. Three historical Nintendo DS repository URLs are recorded as aliases of canonical additions, not extra projects.

## Scope and evidence

The batch combines 15 Amiga/ST projects, 19 CPC/C64 and adjacent eight-bit projects, seven Lynx/BBC/Spectrum/SG projects, four targeted reconstruction/analysis projects, and twenty selected entries from the user-supplied Awesome Game Remakes list. Every project has explicit identity, classification, source/target CPU, build, runtime, AI and relationship audits.

Primary READMEs, source and build files were reviewed. Two official Barbarian source archives were inspected. No candidate game, compiler, emulator or tool was independently built, played or run. Positive flags are bounded upstream reports; missing evidence remains unknown. Reassembly, data round-trip, frame parity and terrain comparisons are not promoted to whole-original-program byte equality. No game-specific guest-CPU wrapper is included. Generic emulators and separate offline analysis oracles are identified as such.

## Discovery avenues and coverage

- Recent batches used DOS reconstruction/native-port searches, Amiga native libraries/OS ports, eight-bit assembly-game searches, author/repository links and explicit supplied leads.
- The current pass ran **78 GitHub queries**: six platform labels (Amiga, Atari ST, Amstrad CPC, C64, SG-1000 and SC-3000), six reconstruction/analysis terms with and without `game`, and platform-plus-`game` searches. Each used `in:readme fork:false` and the first page of up to 100 results. The terms were `reconstruction`, `reverse engineering`, `disassembly`, `decompilation`, `source port` and `reimplementation`.
- Those queries returned 3,337 result occurrences representing 1,622 roots: 344 matched the combined known project/source/decision index, while 1,278 were unmatched before qualification. Twenty queries reached the 100-result cap. These are discovery counts containing substantial noise, not eligible-project counts or an exhaustive GitHub search.
- Creator/community routes included CPC RetroDev source releases, SMS Power source links, amigazen revivals and original projects linked through Atari source collections. Source indexes and mirrors were not promoted as games.
- [Awesome Game Remakes at reviewed commit](https://github.com/radek-sprta/awesome-game-remakes/blob/14780c32653c42635da7bf31fbbdcc660772b995/README.md) contains 366 project bullets, 325 unique GitHub roots (8 known-root overlaps, 317 unmatched) and 40 unmatched non-GitHub primary URLs. Twenty selected projects received primary source/build review and are in this batch. The list is a partially reviewed reference source; its remainder is unqualified.

## Important boundaries

- Barbarian confirmed fields cover only the CPC-derived Windows and Mega Drive variants whose actual BASIC source was inspected. Other versions advertised on the author site are not asserted as source-verified.
- OpenDUNE has separate documented 68000 ST/STE and default 68030 TOS outputs. Compiling with a CPU flag is not used to invent a RAM minimum.
- Geneva and NeoDesk preserve substantial original sources with incomplete build setups. AmigaPython preserves the historical Python 2.0 configuration; Python 2.7.18 is a goal, not a completed port.
- MALUVA’s Amiga implementation is explicitly unfinished. Woods Rescue lacks the Makefile named by its instructions; Zoo Mania has a zero-byte title asset; Uni Games is unfinished.
- Yawi is a partial native SG-1000/SC-3000 puzzle-game implementation. The creator guarantees only its first two of twelve levels are completable.
- ARPABET’s inspected source targets ColecoVision. A linked SG-1000 release does not establish publication of the SG source or compatibility layer.
- Notator’s .SON serialization, Midwinter’s terrain replicas and Neuromancer’s room-zero traces have bounded goals. Midwinter is not a playable engine; Neuromancer is an early room reconstruction. Dork’s Dilemma’s rebuilt display remains broken.
- Amber/Amberstar, Open Kick-Off and Transarctica-2 remain explicitly early/prototype work. Quadromania’s Atari MiNT build is reportedly too slow to play.
- The three RustyPixelsUK Nintendo DS URLs resolve by immutable GitHub repository ID to benbaker76 canonical roots. The existing Kick Off tactic editor, other Manic Miner implementations and DOS Neuromancer reconstruction remain separate lineages.
