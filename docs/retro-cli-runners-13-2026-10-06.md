# Retro command line executable runners

Added 13 approved source-reviewed projects, taking the catalogue from 1,702 to 1,715. These execute original guest binaries through CPU instruction emulation plus host-backed OS APIs. Compilers and utilities can integrate with the host terminal and filesystem without a full-machine boot; supported APIs and guest behavior remain project-specific.

Baseline: main ac4ea751fcdb273322cfdac18cd679b83f03a90f. Reconciled the current catalogue, 1,511 source records, 1,115 decisions and prior-review lineage before promotion. All 13 canonical roots were absent. The run68 variants, Thames original/enhanced sources and riscose mirrors each remain one family. The MS-DOS Player record tracks cracyc/msdos-player with the Takeda upstream identity retained.

Exactly 104 project-specific audit areas were reviewed. No candidate software was built, installed, executed or byte-compared; compilable, runnable, playable and byte_exact remain null. Upstream CI/build/runtime evidence is explicitly attributed, not substituted for independent tests. Host output ISA and guest ISA/OS remain separate. Original guest tools, libraries and media retain their own rights.

All 1,702 prior project and audit objects are preserved, including amitools/vamos, lxa, volamos, DMPP’s corrected 2017-04-07 activity date, the known untouched SDL attribution issue and PR4 attribution labels. **Classification (reviewed):** An emulator with native CP/M BDOS/file and console translation, an 8080/Z80 trace disassembler and optional per-PC CSV profiling. It executes original instructions and synthesizes BDOS/BIOS hooks rather than booting a CP/M disk or requiring an original ROM. Host fopen/fread/fwrite implement FCB file operations. Original guest tools must be supplied with their own overlays/data; this record is the runner, not a full disk/hardware emulator or compiler reconstruction.
