## Scope and verification

The batch contains 17 game reconstruction/disassembly projects; 11 native game ports, remakes or homebrew; one original game source restoration; one game-specific research corpus; 13 tools, firmware or native utilities; five generic emulators; and three demos/visualizations. These distinctions are reflected in typed project fields and eight-area research audits.

Primary repository metadata, READMEs, implementation source, build recipes, recent commits and selected releases/CI were reviewed. No candidate was independently compiled, installed, run or played. Positive build/runtime flags cite bounded upstream evidence; unknown fields stay unknown. No original-platform byte-equality flag is asserted. Generic emulators are not promoted as reconstructed games, and external emulators used for development/verification do not change a native runtime into an emulation wrapper.

## Important limitations

- SWIV-Native has distinct native C/Android implementation, but map comparison does not prove whole-game parity; paths and original assets are user-supplied.
- Vairn/Dune, ChipWits-C, Oh Mummy, Fruity Frank and Sentinel 2nd Look retain incomplete/legacy/WIP limitations. ChipWits-C cannot currently build; Sentinel source lacks complete attack/energy-drain behavior.
- SMS Game Designer's v0.0.1 release says the editor works but its compiler errors. Do not substitute broader README claims for that concrete release limitation.
- Furious Fowls' README state-of-play is partially stale: current source has sound/title/score paths, while other feature and fidelity gaps remain.
- ChipWits-FORTH has disk-based restoration/build instructions; readable Macintosh .forth exports are non-normative and do not compile directly. Apple II source remains unrecovered.
- JETPAC outputs a raw VIC-20 binary that needs loading/relocation, and printed hash comparisons do not establish independently verified byte equality. Temptations' byte-match tests were inspected but not run.
- C64/Plus4 demos, tape/ROM/music tools and generic emulators retain their own categories. Zoo 2019 lacks external include/build paths; Murks64 lacks graphics/audio/media features.
