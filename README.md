## Data model

Canonical records live under `projects/<platform>/*.yml`. See [schema.md](schema.md). Markdown views are generated by `tools/generate_views.py`.

Unknown facts remain **unknown** rather than being inferred as false. This is especially important for AI usage, byte exactness, buildability and project dates.

The legacy [projects.md](projects.md) remains during migration as a human-readable baseline and lead list.

## Tracking

We record both previously-undiscovered historical projects and substantive changes to known projects. See [sources.md](sources.md) for discovery nodes and [log.md](log.md) for dated search state.
