# Legacy Reverse Engineering Tracker

Persistent state for tracking reverse-engineering and source-reconstruction projects targeting **Amiga, Atari ST, ZX Spectrum, Commodore 64, and Amstrad CPC** software.

## What qualifies

Disassembly, decompilation, source reconstruction, binary analysis, reverse-engineering-derived reimplementations, decoded engines/formats, and reproducibly buildable replacements. Recovered original source alone is normally excluded unless it directly supports new reverse-engineering work.

Track both:
1. **Newly discovered projects**, including old/dormant work not previously catalogued.
2. **Substantive updates** to known projects: reconstructed subsystems, major code identification, first successful or byte-matching builds, playable/native ports, releases, significant documentation, new platforms, or renewed development.

Routine commits and trivial progress changes are not report-worthy.

## Files

- [projects.md](projects.md) — known projects and leads
- [sources.md](sources.md) — authors/collections to mine for adjacent projects
- [log.md](log.md) — dated discovery/search state

Baseline established 2026-09-23.
